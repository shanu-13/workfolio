# Website Content — R.A. Shankari

## The concept: "Race Weekend" 🏁

The reference site (pmkrishna.in) tells one continuous story: a train ride ending on a hilltop.
This site tells a race-weekend story instead, because the resume already has it:

- Hosted the **Indian Karting Race** and **Formula Imperial**
- Builds websites for **Automechanika**, an automotive expo
- Shipped **60+ websites**, which is a lot of laps

Each scroll section is a stage of the race weekend: lights out → driver profile → garage → laps → podium → pit radio → chequered flag.

### Mode toggle (the "professional option")

A switch in the nav: **🏎 Race mode** / **👔 Recruiter mode**.
Race mode shows the fun copy. Recruiter mode swaps in the plain, professional copy listed under each section below.
Fun for people browsing, quick for people hiring. The toggle label in race mode: *"Boss is watching? Switch to Recruiter mode."*
